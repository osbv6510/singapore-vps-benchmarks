## 回程精品、去程主干：三网优化究竟优化了哪一段

很多“新加坡 VPS 测评”不会把这两段拆开讲，而这恰恰是判断一台优化机成色的关键。

GoMami 新加坡的**回程**是三网各自精品：电信 CN2 GIA、联通 AS9929、移动 CMIN2。**去程**走的是三网普通主干：电信 163、联通 4837、移动 CMI。官方文档的表述是“三网直连：电信 CN2、联通 AS9929、移动 CMI”，并按源 IP 自动选择最优回程。

为什么这个区分重要？大陆用户访问境外服务器，下载方向（也就是回程）决定网页加载、视频拉流、文件传输的主观感受，上行方向多用于提交数据和上传内容。把预算压在回程上是行业惯例，也是成本最划算的做法。知道这一点，就不会因为看到“去程是 163”而误判整台机器。

自己验货也不难。CN2 GIA 的真伪用 traceroute 就能看出来：

- 全程 59.43.x.x，不出现 202.97 → 真 CN2 GIA
- 国际段 59.43、国内段 202.97 → 其实是 CN2 GT
- 全程 202.97 → 跟 CN2 没关系

这份测试的作者给出的判断是：三网比较均衡，电信略弱且不算特别稳定，联通表现好，移动明显好于同类跨网 CN2 方案。

但移动这条线存在明确分歧。2025 年 12 月 23 日另一份第三方测速里，移动苏州节点下载只有 0.31 Mbps、延迟 256.52ms，而同一次测试中新加坡本地跑到 984.70/942.26 Mbps、香港 45ms。两次测试时间只差半个月，结论完全相反。

比较合理的解释是测试节点、单线程/多线程方式以及当时链路状况的差异。所以对移动方向的结论要留余地：**它能跑得很好，但不是每个地区每个时段都稳。** 如果你的用户集中在某个具体省份，最靠谱的办法是买一个月自己 ping 一遍。

## 常见问题

**新加坡节点延迟到底多少？**
官方文档口径是 < 70ms，官网首页宣传是 < 50ms，两者口径不同。第三方晚高峰实测的 TLS RTT 落在 43–104ms 区间，其中广东联通 43ms、广州移动 54ms、深圳电信 59ms，东北移动 104ms。

**$29 的 Nano 够用吗？**
2 核 2GB / 40GB / 500GB 单向流量。跑一个日 PV 几千的 WordPress、做代理落地、或当月度测试机，够。要同时跑数据库和缓存、或者一个月流量超过 500GB，直接看 Mini 以上。

**移动用户能不能买？**
能，但移动方向波动大，同一个机房不同时段的第三方测速差异明显，你所在省份的实际表现测一个月才算数。

**能装 Windows 吗？**
支持列表含 Windows Server 2019/2022，对应 Pro 和 Ultra 两档标注了 Windows-ready，但官方文档没说 License 来源，采购前建议开工单问清楚授权方式。

**流量超了会怎样？**
可能被限速，具体限到什么程度官方没给数字，只写“取决于产品规格”。跑大流量的业务建议直接上 Pro，5TB 单向配 3Gbps 口更从容。
